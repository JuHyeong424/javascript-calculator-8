# 문자열 덧셈 계산기

## 기능 목록

- [ ] **기본 구분자**
    - [ ] 쉼표(`,`) 또는 콜론(`:`)을 구분자로 사용해 숫자의 합을 계산한다.
    - [ ] 빈 문자열은 0을 반환한다.
- [ ] **커스텀 구분자**
    - [ ] `//`와 `\n` 사이의 문자를 커스텀 구분자로 사용해 합을 계산한다.
- [ ] **예외 처리**
    - [ ] 잘못된 값을 입력하면 `[ERROR]` 메시지와 함께 에러를 발생시킨다.
- [ ] **입출력**
    - [ ] 지정된 형식으로 문자열을 입력받고, 결과를 출력한다. (`결과 : 6`)
